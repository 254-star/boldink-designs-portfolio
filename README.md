# SECURITY

Security is mandatory.

Follow the latest **OWASP Top 10** best practices.

Protect against:

* Cross-Site Scripting (XSS)
* Cross-Site Request Forgery (CSRF)
* SQL Injection
* NoSQL Injection
* Command Injection
* Server-Side Request Forgery (SSRF)
* Directory Traversal
* Clickjacking
* MIME Sniffing
* Open Redirects
* Email Header Injection
* Brute-force attacks
* Automated bots
* Session fixation
* Dependency vulnerabilities

### Contact Form Security

* Validate on both client and server.
* Sanitize all inputs.
* Escape rendered output.
* Rate-limit submissions.
* Prevent duplicate submissions.
* Use CAPTCHA or Cloudflare Turnstile.
* Return user-friendly errors only.
* Never expose stack traces or server details.

### Secrets Management

* Store all API keys and secrets in environment variables.
* Never expose secrets to the client.
* Use HTTPS exclusively.

### Security Headers

Configure:

* Content-Security-Policy (CSP)
* Strict-Transport-Security (HSTS)
* X-Frame-Options
* X-Content-Type-Options
* Referrer-Policy
* Permissions-Policy

### Future Authentication

Architect the application to support future features without major refactoring:

* Secure admin dashboard
* Portfolio management
* Blog/CMS
* Analytics
* User authentication
* Role-based access control
